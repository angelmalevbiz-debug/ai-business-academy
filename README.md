# AI Business Academy

Българска платформа за работа с AI, бизнес инструменти, практически примери и общност. Next.js 16, React 19, TypeScript и SQLite с постоянно сървърно съхранение.

## Стартиране на VPS

Виж **[инструкциите за VPS](docs/DEPLOY_VPS.md)** за Docker, домейн, HTTPS, администратор, архивиране и обновяване.

Хранилището съдържа приложението и необходимите продуктови изображения. Локалната база, профилите, паролите, качените от потребители файлове и частните отчети не се качват. Нова инсталация започва с празна база; съществуващи данни се пренасят отделно и по защитен канал.

## Локална разработка

Изисквания: **Node.js 24.14+**, npm и постоянен диск за данните. Не е необходим отделен сървър за база данни.

```bash
npm ci
npm run dev -- --port 3100
```

Отвори [http://127.0.0.1:3100](http://127.0.0.1:3100). Настройките са описани в [.env.example](.env.example). За локални стойности създай `.env.local`; този файл е изключен от Git. Продукционните настройки се подават от средата на VPS.

## Какво има в приложението

- Вход, личен профил, роли и администратор; лична работа и общност със сървърно съхранение.
- Визуални бизнес примери, личен напредък, план за деня и фокус.
- Workflow с контекст за бранда, задачи за AI роли, преглед на резултати и одобрения.
- Създаване на бизнес сайтове с отраслова структура, адаптивна визия, визуален редактор и HTML експорт. Вграденият дизайнер работи без платен AI API. Снимки от Wikimedia Commons се намират през интернет; възможно е и качване на собствени.
- Незадължителен собствен Ollama сървър за AI промени по сайтовете. Локален или отдалечен модел се настройва изрично; няма автоматично преминаване към платен доставчик.
- Връзки с външни услуги чрез отделна конфигурация на оператора и разрешение на всеки потребител.

Това хранилище само по себе си не предоставя AI модел, акаунти във външни услуги или разрешение за публикуване. Workflow worker е отделен процес. Видео обработката използва външен publisher проект; той не е част от това хранилище. Публикуване, реклами и интеграции изискват реални акаунти и съответните настройки. Наличието на интерфейс не означава, че тези услуги са вече свързани.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Браузърните проверки използват отделна база и порт:

```bash
npx playwright install chromium
npm run test:e2e
```

За проектен администратор използвай `npm run admin:create` с `ADMIN_EMAIL`, `ADMIN_PASSWORD` и незадължително `ADMIN_NAME`. Паролата трябва да е поне 12 знака. Никога не записвай реалните стойности в Git.

## Данни и лицензирани зависимости

При липса на `COMMUNITY_DB_PATH` базата е `.data/community.db`. Качванията и работните файлове също се пазят в `.data/`. На VPS тази директория трябва да е върху постоянен диск. За SQLite архив използвай `npm run db:backup`; архивирай отделно и качените файлове.

Запазените лицензи и произходът на включения външен код са описани в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) и `lib/vendor/`. Хранилището няма лиценз за свободно преизползване на собствения продуктов код.

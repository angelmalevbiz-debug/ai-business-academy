# Първи работещ поток: разпредели тестово запитване

Учебна демонстрация с измислени данни. Нищо не се изпраща до клиент.

**Вход → правило → видима категория**

## Какво ти трябва

Наличен n8n акаунт или инсталация. Техните условия и евентуални разходи са отделни от безплатното обучение. За този поток няма AI услуга, API ключ или външен достъп.

## Свържи петте възела

```text
Manual Trigger → Edit Fields → If
                              ├─ true  → Edit Fields: category = Оферта
                              └─ false → Edit Fields: category = За проверка
```

1. Създай празен workflow и добави **Manual Trigger**.
2. След него добави **Edit Fields (Set)**. Избери **Manual Mapping** и добави текстово поле `message` със стойност `Искам оферта за сайт.`.
3. Добави **If**. За лявата стойност избери **Expression** и постави:

   ```javascript
   {{ String($json.message ?? '').toLowerCase().includes('оферта') }}
   ```

   Избери **Boolean → is true**.
4. Свържи изхода **true** с нов **Edit Fields**. Добави текстово поле `category` със стойност `Оферта`.
5. Свържи **false** с друг **Edit Fields**. Добави `category` със стойност `За проверка`.
6. Изпълни ръчно целия workflow. Отвори изпълнения краен възел и виж `category` в неговия output.

Имената на контролите може да се различават по версия. Източниците по-долу са официалната отправна точка при разлика.

## Провери какво действително прави

Сменяй `message` в първия **Edit Fields** и изпълнявай целия workflow отначало.

| Вход | Желан резултат според смисъла | Какво ще даде това правило |
|---|---|---|
| Искам оферта за сайт. | Оферта | Оферта |
| празен текст | За проверка | За проверка |
| Колко струва сайт? | Оферта | За проверка: пропуск |
| Не искам оферта. | За проверка | Оферта: грешка |
| Помогнете ми. | За проверка | За проверка |

Третият и четвъртият ред са целенасочено трудни. Правилото търси дума; то не разбира намерение. Не прикривай тези грешки с ново описание на успеха.

Свали `request-test-cases.csv` и запиши собствения получен резултат, времето за преглед и следващата промяна. Таблицата съдържа очаквания, а не доказателство, че твоят поток е тестван.

## Кога си готов за следващия урок

- Видя резултат от цялото изпълнение.
- Записа поне един успешен и един неуспешен пример.
- Можеш да обясниш ограничението на правилото.

Това още не е внедряване: няма реален формуляр, съхранение, права за достъп или надеждно разбиране на свободен текст. Използвай наученото, за да планираш следващия тест. Първо човек проверява категорията; не свързвай автоматично изпращане на съобщения.
